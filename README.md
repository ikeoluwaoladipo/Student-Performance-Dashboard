# Student Performance Dashboaard
Power BI dashboard analyzing student performance, test scores, and factors affecting academic outcomes.

## Project Overview

This project is a Power BI data analysis and visualization project based on a student performance dataset.

The analysis examines students' performance across Mathematics, Reading, and Writing and explores how different student and family-related factors are associated with test scores.

The goal of the project is to turn the raw student data into a clear and interactive dashboard that makes performance patterns easier to understand and communicate.

---

## Analytical Problem

Student performance data contains several variables that can be difficult to interpret when viewed as raw records.

This project was developed to answer questions such as:

- How are students performing overall?
- Which subjects have the highest and lowest average scores?
- How does performance differ by gender?
- How does parental education relate to student performance?
- What relationship exists between test preparation and performance?
- How do Mathematics and Reading scores relate to each other?
- How are students distributed across different performance categories?

---

## Project Objectives

The objectives of this analysis were to:

1. Clean and prepare the student performance dataset.
2. Analyze overall and subject-level performance.
3. Compare performance across different student groups.
4. Examine factors associated with test scores.
5. Develop meaningful KPIs for quick performance assessment.
6. Build an interactive Power BI dashboard for presenting the findings.

---

---

## Analysis Performed

### Subject Performance

The dashboard compares average scores across Mathematics, Reading, and Writing to identify differences in subject performance.

### Gender Analysis

Student performance is compared across gender categories to identify differences in average test scores.

### Parental Education

The analysis examines student performance across different parental education levels.

### Test Preparation

The dashboard compares students based on whether they completed a test preparation course, providing a way to examine its relationship with test performance.

### Performance Categories

Students are grouped into performance categories to provide a clearer view of the distribution of academic outcomes.

### Score Relationship

The dashboard also examines the relationship between Mathematics and Reading scores.

---

## Key Insights

The analysis shows that:

- Reading has the highest average score among the three subjects at 69.17.
- Mathematics has the lowest average score among the three subjects at 66.09.
- Writing has an average score of 68.05.
- The overall average score across the analyzed subjects is 67.77.
- Student performance varies across gender, parental education, and test preparation categories.
- The dashboard provides a visual view of the relationship between Mathematics and Reading performance.
